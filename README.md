# 💼 Clínica Transformação

🔗 **Acesse o site:** [https://clinica-transformacao.vercel.app](https://clinica-transformacao.vercel.app)

Landing Page desenvolvida como **projeto freelancer** para a Clínica Transformação, uma instituição especializada em saúde mental e reabilitação. O objetivo foi criar uma presença online **responsiva, acessível e informativa**, destacando os serviços, missão e estrutura da clínica.

## 🛠️ Tecnologias Utilizadas

* **HTML5 + Tailwind CSS** – Estrutura semântica e design responsivo
* **JavaScript (vanilla + jQuery)** – Interatividade e animações
* **Swiper.js + Slick Carousel** – Carrosséis de imagens e logos
* **AOS (Animate On Scroll)** – Animações suaves ao rolar a página
* **Google Fonts** – Estilo com Playfair Display e Lora
* **Google Analytics + Tag Manager** – Rastreamento de eventos e SEO

## ✨ Funcionalidades

* Layout 100% responsivo (mobile-first)
* Carrossel de imagens das instalações
* Slider contínuo de parceiros/conveniados
* Animações suaves ao rolar a página
* Integração com WhatsApp (botão flutuante)
* SEO otimizado com meta tags
* Rastreio de eventos com Google Analytics

├── images/      # Logos, ícones, carrossel

## ▶️ Como Executar

```bash
git clone https://github.com/usuario/clinica-transformacao.git
```

Abra o arquivo `index.html` diretamente no navegador.
Não é necessário servidor local — todas as dependências são via CDN.
Certifique-se de manter a estrutura de pastas (`images/`, `css/`, `js/`) no mesmo diretório.
